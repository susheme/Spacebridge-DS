## Заметки

Реализован 10.11.2026. Неделя начинается с понедельника. Дни — штатные
Button Small (Primary для выбранной даты, Text для остальных), стрелки —
Button с существующими arrow-drop-left/right-line. Оформление календаря —
общие токены border, radius, padding, gap, цвета и классы типографики DS.
Новых токенов, иконок и сторонних зависимостей нет.

API: `sbMkDatepicker({ value, min, max, locale, inline, disabled, label })`.
Даты — YYYY-MM-DD, locale — en/ru. По умолчанию раскрывается через Popover;
inline:true показывает календарь сразу. Триггер — Button, ручного ввода нет.
Выбор отправляет всплывающее событие `sb-date-change`, `event.detail.value`.
В popup-режиме панель закрывается после выбора. Escape и возврат фокуса — Popover.

Диапазон дат и ручной ввод полной даты не реализованы. Для клавиатуры
доступны Tab и Enter/Space на кнопках. Перемещения стрелками по дням пока нет.
Code panel отдаёт разметку и CSS; для интерактивного поведения нужен JS DS.

Проверки: `jsc tests/datepicker.js` (февраль, min/max, смена года) и общий
`jsc tests/run.js`. Геометрия и внешний вид в браузере ещё не проверены.

Встроенный календарь без тени. Выпадающий режим использует `sbMkPopover` + `sbMkContextCard`: поверхность и тень штатной Context Card. Меню месяца/года — существующий Selector (Popover + Context Menu); скролл ограничен самой Context Card, внешняя оболочка не обрезает её тень.

По референсу старой DS: отдельные штатные Selector для месяца и года, 42 дня с соседними месяцами, выходные через info, соседние даты через text-secondary. Убраны нижний статус и рамка сегодняшнего дня. Годы без min/max: текущий отображаемый год ±100.

Меню месяца/года ограничены шестью высотами поля и доступным местом над/под якорем, со скроллом к выбранному пункту. В Selector встроен текстовый input со стилями Input DS: год — четыре цифры, месяц — полное локализованное название или 1–12. Enter/change применяют, Escape восстанавливает значение, ArrowDown открывает список. Ошибочный ввод помечается aria-invalid; min/max ограничивают навигацию.
