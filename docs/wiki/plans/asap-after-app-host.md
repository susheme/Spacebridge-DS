## Что подтвердилось (не трогать)

- pkg-CSS самодостаточен: три экрана без единого стилевого файла кроме бандла.
- Фабрики пригодны как генератор статики (страницы демо собираются jsc-скриптом).
- Процесс с иконками работает: дизайнер кладёт SVG в Icons/ → paths в ICON_PATHS (filter/undo/save за один заход).
- Layout-грабли ловятся только computed-проверкой в браузере — тесты это не покрывают (известно из infra/tests.md), демо-цикл с _debug-страницей себя оправдал.
