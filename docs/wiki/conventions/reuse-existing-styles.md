# Сначала ищи готовый стиль

> Не изобретать новые font/color/spacing значения. Сначала grep по DS на ближайший существующий класс/токен. Новый класс — только если совсем нет аналога, и тогда явно согласовать.

При создании нового компонента / нового состояния / нового стиля **сначала ищи максимально близкие существующие значения, стили, классы, токены в DS**. Изобретать с нуля — последний вариант.

**Why:** иначе плодим типографические/цветовые «двойники» и DS теряет единство. Юзер прямо сформулировал это правило (2026-05-12, в контексте `.pg-group-title`).

**How to apply:**

1. **Типографика** — перед `font-size`/`weight`/`line-height` ищи существующий `sb-*` класс:
   - `sb-title-l/m/s` (с regular-вариантами), `sb-body-l/m/s`, `sb-sub`, `sb-caption`, `sb-h1-h8`
   - Component-classes как `sb-field-label`, `sb-btn-text`, `sb-badge-text`
   - Если нужный размер/вес есть → используй существующий класс в HTML
   - Если близкое есть, но weight/size чуть другой → согласуй с юзером, **создавай новый класс явно** (например `sb-title-s-semibold` рядом с `sb-title-s-regular`), не лепи inline `font-*`

2. **Цвета** — только `var(--token)`. Если нужного оттенка нет, **не изобретай** — спроси, согласуй добавление в `js/tokens.js`.

3. **Spacing / radius / border-width** — токены `--pad-*`, `--gap-*`, `--radius-*`, `--border-width-*`. Если нет в Figma JSON — hardcoded + комментарий «согласовать с дизайнером», не lebr новый токен сам.

4. **Состояния / варианты компонента** — копируй с эталона (Buttons как референс) перед изобретением своего паттерна (см. memory: disabled = `--border` text для текстовых полей; opacity-only для навигационных).

5. **Поиск:**
   ```
   grep -rn "<term>" css/ js/components/
   grep -rn "font-size\|font-weight" css/components/<similar>.css
   ```
   3 минуты grep'а спасают полчаса рефакторинга.

**Конкретный кейс (2026-05-12):** `.pg-group-title` я сначала сделал с `--title-font-size-s` / `--font-weight-semibold` — это не матчило ни sb-title-s (14/bold), ни sb-field-label (16/semibold). Юзер указал на это, попросил использовать тот же стиль что у инпут-лейблов → переехал на `sb-field-label` через добавление класса в HTML.
