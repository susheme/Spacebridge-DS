# Updates (колокольчик)

> Колокольчик обновлений в Spacebridge DS — updates.js готов, панель/попап/модалка ждут Figma

Фича «колокольчик обновлений» в Spacebridge DS (старт 03.09.2026).

**Сделано:** `js/updates.js` — лента SB_UPDATES (16 записей, по одной на релиз CHANGELOG.md, id = 'v'+version, title/text = {en,ru}, component = NAV-id для перехода) + хелперы: `sbUpdatesHasUnseen/MarkSeen` (ключ `sb-updates-seen` — бейдж и попап), `sbUpdatesIsRead/MarkRead/UnreadCount` (ключ `sb-updates-read` — точки в панели). Грузится после docs-i18n.js. Тесты зелёные. Колокольчик уже в Nav Bar (первым в right slot, до lang switcher, `id="updatesBellBtn"`): unseen → `notification-3-fill`, иначе line; клик пока не подключён. Попутно починен path `notification-3-line` в ICON_PATHS (был чужой залитый Material-колокольчик).

**Согласованная логика (обновлено 03.09):** новый верхний id → попап со стрелкой (Popover) + смена иконки на fill (бейдж); попап гаснет по клику мимо/~5 сек; открыл панель → MarkSeen, иконка → line; внутри панели точки непрочитанного. Панель = стопка КАРТОЧЕК (по образцу ленты YouGile, но без картинок и счётчика комментов): title + 1–2 предложения + футер (дата, бейдж версии). Клик по карточке → модалка (Dialogues: полный текст, версия/дата). Переходы к компонентам — КНОПКИ `sbMkButton({variant:'link', href:'#id'})` в ряду (Tag Line, flex gap 8; сначала были sb-link-m, 04.09 заменены на новый Button-вариант Link: бокс Rounded-S 24, padding 0, radius 2, фон --background, типографика Link S 14/500 underline, цвет --primary; ховер спекой не задан; с critical/size не сочетается); тип «Notification Card» СОБРАН на странице Cards: bordered + шапка `titleCls:'sb-title-m'` + дата Subscription + бейдж success «New» + слот is-alert + линк-ряд. Кликабельные теги ОСТАВЛЕНЫ в Tags как вариант DS, но в карточках ленты не используются. Устарело ниже: КЛИКАБЕЛЬНЫЕ ТЕГИ (`sbMkTag({onClick})`, сделан 03.09: `<button class="sb-tag filled clickable">`, ховер = тень Hover-blue, stopPropagation зашит, с removable не сочетается) в карточке (ряд + `mode:'more'` «+N») и в модалке (полный набор). Кнопка «Перейти к компоненту» отменена. В данных `components: []` — массив NAV-id (v1.7.0 — четыре, v1.0.0 — 18). MarkRead = открытие модалки или клик по тегу. Ховер-тултип на карточке отменён. Карточки панели: `sbMkCard({border:true, interactive:true})` — модификатор bordered сделан (см. [cards](cards.md)).

**04.09 ПАНЕЛЬ СОБРАНА** — компонент Side Panel (`side-panel.js/css`, NAV id `side-panel`, inProgress): фикс 320 (--side-nav-min-max-width), высота 720–2000, radius 16, Shadow-L; хедер = Header S (title + close-line + sbMkSearch в СУБ-СЛОТЕ tabs — спека «Header S + Search Bar» это и есть Header S с сабом), не скроллится, повторяет радиус 16/16/0/0; скролл-зона .sb-side-panel-content (padding 0/16/16, gap 8, overflow-y auto, min-height 0 обязателен). Паддинги спеки панели (0/16/16/16) несёт скролл-зона — хедер full-bleed (иначе двойные 16 и распор min-width 320). `sbMkSidePanel({header, content, cls, attrs})`. В status.js добавлен экспорт `sbMkMark({variant, sm})` — Mark (полоска 3×40) идёт в lead-слот Notification Card как сигнал непрочитанного (success=релиз, error=аларм, прочитанная — без Mark). 07.09 фиксы хедера: (а) контекстный `min-width: 0` в side-panel.css на Header S и его tabs-слот (распор серча за край); (б) Header S научен комбинации topRight+tabs — с добром юзера: класс top-right не вешается, вместо него ряд `.sb-header-s-head` (left+title+right), корень колонкой, суб-слот ниже; демо панели с `topRight: true`. Старые потребители top-right без tabs не задеты. 07.09 ИНТЕГРАЦИЯ ГОТОВА — `js/updates-ui.js` (докс-слой, пара к updates.js): колокольчик onclick=sbUpdatesOpen() → Overlay `sb-updates-overlay` (панель справа-сверху, min-height через min(720, 100vh-32)) с Side Panel и картами из SB_UPDATES; unread → Mark success + бейдж New; date формат sbT(en/ru) из ISO; лейблы ссылок из NAV (sbNavItems); клик по ссылке → MarkRead + закрытие панели; открытие → MarkSeen + sbUpdatesBellRefresh() (fill↔line); поиск = фильтр карточек по textContent. Осталось: попап «есть новое» на колокольчике (Popover), модалка записи (БЛОКИРОВАНА: Dialogues — стаб, ждёт спеку).

**Решения юзера:** колокольчик в Nav Bar справа (иконка `notification-3-line/fill`); Side Panel / Drawer формализуем как DS-компонент с playground'ом; **блокер — ждём макет Figma** на панель/попап (догма: без макета не верстать).

**Замечено:** CHANGELOG.md отстаёт — Popover, Property List, Cards+Placeholder закоммичены после релиза 1.14.0 и в changelog не описаны; при релизе 1.15.0 добавить запись в SB_UPDATES.
