# Догма: хэдэр контейнера — sticky

Указание юзера, 14.09.2026 (ревью demo/app-host).

Хэдэр скроллящегося контейнера — страницы, карточки, панели — прилипает к
верху своей зоны прокрутки, а не уезжает вместе с контентом. Относится к
Header L/M/S на страницах и к `sb-card-header` карточек с собственным скроллом.

Как применять:

- `position: sticky; top: 0` + непрозрачный фон поверхности + z-index выше контента.
- Прилипает хэдэр к СВОЕЙ зоне прокрутки: у страницы это scroll-контейнер
  контентной зоны, у скроллящейся карточки — сама карточка.
- Смежное: sticky-вариант Section Header в компонент сознательно не вынесен
  (BACKLOG); Header S умеет sticky ([../plans/dogfood-headers.md](../plans/dogfood-headers.md)).
  Эта догма о поведении в продуктовых экранах, не о правке компонентов.

Живой пример — `demo/app-host` (Header L страниц Events / Management).
